# سیستم طراحی وب

ui-ux-pro-max برای crypto market Persian dashboard اجرا شد. Minimalism مبنای چیدمان است؛ پیشنهاد صفحه فروش و فونت لاتین کنار گذاشته شد. جست‌وجوی اولیه stack بدون نتیجه بود؛ جست‌وجوی accessible cards responsive سه راهنمای کارت، فاصله و نام دسترس‌پذیر کنترل‌ها داد. پیاده‌سازی CSS بومی از همان اصول استفاده می‌کند.

رنگ‌ها همان خانواده MASTER: زمینه تیره #0B1220، سطح #121D30، متن #F8FAFC، ثانویه #B0BFD3، تأکید #93B4FF؛ روشن زمینه #F4F7FC و سطح سفید و متن #0F172A و ثانویه #475569. رشد/افت علاوه بر رنگ علامت دارند. فونت محلی Vazirmatn، اندازه‌ها rem، خط ۱٫۷، کنترل‌های ۴۸px و outline تمرکز ۳px.

دسکتاپ: navigation سمت راست، نمای کلی سه‌ستونه، جدول بازار، جزئیات نمودار/آمار. در عرض زیر ۹۰۰ نوار مسیرها بالای محتوا و زیر ۵۰۰ بازار به ردیف‌های دوخطی تبدیل می‌شود. خبرها دو ستون و در گوشی یک ستون‌اند. متن بزرگ نباید باعث قطع قیمت یا تیتر شود؛ قیمت و درصد با bdi/LTR، نمودار LTR و تاریخ تهران/شمسی است. سطح لمس، skip link، semantic table، label، aria-pressed، live status و prefers-reduced-motion رعایت می‌شوند.

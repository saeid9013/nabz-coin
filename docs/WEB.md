# نسخه وب نبض کوین

طبق درخواست کاربر، اولویت فعلی نسخه وب است؛ کار APK به بعد از اتمام وب منتقل شد. نسخه وب در apps/web مستقل از Flutter اجرا می‌شود. HTML/CSS و ES modules بومی مرورگر، بدون وابستگی runtime npm؛ فونت Vazirmatn و مجوز OFL محلی هستند.

## اجرا

```powershell
cd F:\CoinMarketCap
python scripts/serve-web.py --port 8080
```

آدرس: http://127.0.0.1:8080. حالت پیش‌فرض دمو شامل ۱۰۰ کوین نمونه و دو محتوای آموزشی با برچسب صریح است. قیمت، روند و خبر دمو واقعی نیستند. منابع اصلی در صفحه جزئیات قابل باز شدن‌اند.

برای اتصال بک‌اند، API را طبق README اجرا کنید و سرور وب را با `python scripts/serve-web.py --port 8080 --api-url http://127.0.0.1:8000` راه‌اندازی کنید. سپس در تنظیمات وب «بک‌اند واقعی» انتخاب شود. بک‌اند نیز باید APP_MODE=live باشد؛ کلید فقط در environment سرور. کلاینت live پاسخ demo را رد می‌کند و خطا را نمایش می‌دهد. proxy فقط GET عمومی به origin تنظیم‌شده می‌فرستد؛ cookie و Authorization منتقل نمی‌شوند.

برای استقرار واقعی، فایل‌های apps/web را با HTTPS سرو کنید و reverse proxy مسیر /api/v1/ را به FastAPI متصل کنید. سرویس serve-web فقط ابزار توسعه روی loopback است. دامنه، خرید و انتشار عمومی انجام نشده‌اند.

## قابلیت‌ها

- بازار، جست‌وجوی محلی فارسی/نام/نماد، رتبه/رشد/افت، قیمت USD و نمای کلی؛ جست‌وجو به ۱۰۰ کوین محدود است.
- جزئیات کوین، بازه‌های ۱/۷/۳۰ روز، زمان قدیم به جدید در LTR و جدول دسترس‌پذیر نقاط؛ پاسخ دیررس روی بازه جدید نوشته نمی‌شود.
- اخبار، صفحه جزئیات، منبع اصلی، pagination، ذخیره، فیلتر کوین و اشتراک/کپی لینک با خطای قابل فهم.
- واچ‌لیست، ذخیره اخبار، تم و اعداد فارسی و اندازه متن در localStorage؛ اطلاعات بین دستگاه‌ها sync نمی‌شوند.
- کش live به تفکیک origin و endpoint، برچسب آفلاین/قدیمی و زمان تهران؛ 403/429 و پاسخ demo با کش مخفی نمی‌شوند.
- Service worker پوسته و فونت‌ها را پس از اولین بازدید موفق ذخیره می‌کند؛ API از آن عبور می‌کند و کش داده فقط در DataClient است. HTTPS یا localhost لازم است. پاک کردن داده مرورگر ذخیره‌ها را حذف می‌کند.

## شواهد QA

`cd apps/web; npm run check; npm test`: ۶ تست موفق؛ search/sort/watch scope، قیمت بسیار کوچک، escaping و URL، نمودار زمان‌دار، offline/restart، تفکیک origin، لغو درخواست و رد demo/403.

`python scripts/smoke-web.py`: تحویل فایل‌های وب، proxy به FastAPI واقعی در حالت demo، نمودار ۴۸ نقطه و رد range نامعتبر آزموده شد. این آزمون اتصال CMC واقعی نیست.

در مرورگر واقعی: جست‌وجوی BTC، علاقه‌مندی و حفظ پس از reload، جزئیات کوین، تغییر range و جدول ۴۸ نقطه، ذخیره و فیلتر خبر، صفحه جزئیات و لینک منبع بررسی شدند. عرض ۳۶۰ با تم روشن/متن ۱۵۰٪ و ۴۱۲ برای جزئیات کوین بررسی شد؛ scrollWidth صفحه برابر clientWidth بود. جدول بازار در گوشی به ردیف‌های چندخطی تبدیل شد و overflow آن نیز حذف شد. تم تیره دسکتاپ در ۱۴۴۰ بررسی و تصویر واقعی ثبت شد. خطای console در بررسی دسکتاپ مشاهده نشد.

تصاویر در docs/screenshots/web-*.jpg هستند؛ تصویر viewport واقعی‌اند، نه تصویرسازی. بررسی دستی TalkBack، نصب PWA، شبکه CMC و کیفیت ترجمه live هنوز انجام نشده‌اند. اشتراک سیستم ممکن است بسته به مرورگر متفاوت باشد.

آزمون آفلاین واقعی پوسته: سرور وب متوقف شد؛ reload مرورگر همچنان بازار ۱۰۰ کوین و اخبار را نمایش داد. سپس سرور روی 8080 دوباره راه‌اندازی شد. حالت live بدون proxy نیز در مرورگر خطای روشن داد و دمو نمایش نداد؛ پس از QA حالت دمو بازگردانده شد.

## اتصال فعال محلی
در این اجرا CoinMarketCap واقعی متصل شد. دستور `python scripts/run-live.py` هر سه سرویس را راه‌اندازی می‌کند؛ کلید در فایل ignored سروری .tools/live/secrets.json قرار دارد. تنظیم عمومی /web-config.json فقط mode را اعلام می‌کند، هیچ کلیدی برنمی‌گرداند. بعد از تغییر نسخه پوسته، صفحه را دوبار reload کنید تا service worker جدید فعال شود. اگر حالت دمو باقی ماند، از تنظیمات «بک‌اند واقعی» را انتخاب کنید.

HTTP 200 بازار ۱۰۰ کوین و overview واقعی تأیید شدند؛ تست‌های فعلی ۴۳ بک‌اند و ۹ وب موفق‌اند. زمان‌بندی قیمت ۱۰ دقیقه و overview ۳۰ دقیقه؛ قابلیت‌های اختیاری پولی خاموش‌اند. کلید واردشده در گفتگو باید بعد از پایان راه‌اندازی از داشبورد CMC تعویض و فقط فایل سروری به‌روز شود.

# دانشنامه فارسی

فایل کاربر با scripts/import-encyclopedia.py به پیش‌نویس خصوصی تبدیل می‌شود. ۱۰۹ ردیف برای بازبینی باقی ماند و ۳۹۱ الگوی نمونه حذف شد؛ ۱۲ اصطلاح نیز پیش‌نویس‌اند. فایل اصلی تغییر نکرده است.

محتوای عمومی در apps/web/content/encyclopedia.json است: ۲۰ معرفی کوتاه با لینک رسمی و تاریخ بازبینی؛ تاریخچه و تیم فعلاً برای BTC و ETH بررسی شده و بقیه این بخش‌ها هنوز تأیید نشده‌اند. این تعداد رتبه‌بندی ۲۰ ارز برتر امروز نیست. داده مالی اکسل وارد برنامه نشده است. اتصال بر اساس شناسه CMC و نماد، هر دو، انجام می‌شود. در بازار فعلی ۱۸ مدخل حضور دارد.

برای توسعه، متن را بر اساس سند رسمی بازنویسی و منبع و reviewed_at ثبت کنید؛ ادعای تأیید کامل صرفاً با بررسی همه فیلدها مجاز است. رتبه، قیمت، تغییر روزانه و ATH دستی نباید وارد این فایل شوند. برای گسترش به صدها مدخل می‌توان API و جدول محتوای تحریریه افزود؛ نسخه فعلی JSON کوچک با کش آفلاین است.

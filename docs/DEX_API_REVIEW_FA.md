# بررسی و اتصال API عمومی DEX Screener

بررسی مستند رسمی و درخواست واقعی در ۱۴۰۵/۰۷/۱۴ انجام شد. ثبت‌نام و کلید جدید لازم نبود. API برای پایش نقدینگی، حجم، تغییر قیمت، تعداد خرید/فروش، قراردادها، توکن‌های تازه، داده تبلیغاتی و روند دسته‌های بازار مفید است. همه ۱۳ خانواده مسیر مستند به جمع‌آوری دوره‌ای متصل شدند؛ این به معنی دانلود تمام پایگاه داده DEX نیست.

| مسیر | استفاده در برنامه |
|---|---|
| token-profiles/latest/v1 | پروفایل‌های جدید و لینک‌های پروژه، با اتصال به جفت همان قرارداد |
| token-profiles/recent-updates/v1 | پروفایل‌هایی که اخیراً به‌روز شدند |
| community-takeovers/latest/v1 | ادعای واگذاری پروژه به جامعه و زمان ثبت |
| ads/latest/v1 | نوع تبلیغ، زمان، مدت و تعداد نمایش در صورت وجود |
| token-boosts/latest/v1 | Boost جدید و مقدار آن |
| token-boosts/top/v1 | بیشترین Boost پولی؛ از محبوبیت طبیعی جدا است |
| metas/trending/v1 | دسته‌های ترند، تعداد توکن، ارزش بازار، حجم و نقدینگی |
| metas/meta/v1/{slug} | جفت‌های دسته و تغییر ارزش بازار در ۵ دقیقه، ۱/۶/۲۴ ساعت |
| orders/v1/{chainId}/{tokenAddress} | سفارش تبلیغاتی، وضعیت و پرداخت در جزئیات JSON؛ نمونه ۱۰ توکن برتر Boost |
| latest/dex/search | جست‌وجوی دوره‌ای BTC/ETH/SOL و ذخیره جفت‌های نتیجه |
| latest/dex/pairs/{chainId}/{pairId} | دریافت مستقیم جفت مشاهده‌شده |
| token-pairs/v1/{chainId}/{tokenAddress} | بررسی مستقیم بازارهای یک قرارداد مشاهده‌شده |
| tokens/v1/{chainId}/{tokenAddresses} | بازارهای توکن‌های فید، در بسته‌های حداکثر ۳۰ آدرس |

## آنچه کاربر می‌بیند

کاوش ← بازار DEX، ده تب شامل جفت‌ها، هفت فید، سفارش‌ها و داده/API. جفت‌ها فیلتر شبکه و جست‌وجوی نام/نماد/قرارداد دارند؛ مرتب‌سازی حجم، نقدینگی، رشد، تراکنش و تازگی جفت، همراه صفحه‌بندی ۳۰تایی. جزئیات چهار بازه زمانی، مقدار نقدینگی هر توکن، FDV و ارزش بازار، قیمت ارز مقابل، زمان ایجاد، سه آدرس قرارداد، برچسب جفت و لینک پروژه را نشان می‌دهد. مقدار غایب «—» است. داده‌ها با شناسه شبکه و آدرس جفت یکتا هستند؛ به کوین CMC با تشابه نماد متصل نشده‌اند.

در دریافت اولیه: ۶۱۴ جفت، ۳۰ پروفایل جدید، ۳۰ به‌روزرسانی، ۸ واگذاری به جامعه، ۳۰ تبلیغ، ۳۰ Boost جدید، ۳۰ Boost برتر، ۱۸ دسته و سفارش ۱۰ توکن؛ ۴۷ پاسخ HTTP موفق در اسنپ‌شات. شمارش‌ها در دریافت بعدی تغییر می‌کنند. داده خام تمام پاسخ‌های همین اسنپ‌شات با درخواست /api/v1/discovery/dex?include_raw=true از کش و در تب «داده و API» قابل دانلود است؛ پاسخ عادی raw ندارد تا سبک‌تر بماند. فیلدهای اضافی منبع حذف نمی‌شوند. عکس و بنر نیز در خروجی خام باقی می‌مانند.

## حدود و دریافت

دریافت هر ۱۵ دقیقه، فقط در scheduler و از api.dexscreener.com؛ API عمومی سایت کش می‌خواند. سقف هر دور ۳۰۰ آدرس توکن، ۲۰ دسته، ۱۰ بررسی سفارش و ۲۰ شبکه برای batch است. جست‌وجوی UI داخل مجموعه ذخیره‌شده انجام می‌شود؛ درخواست دلخواه کاربر مستقیم به upstream ارسال نمی‌شود. فیدهای ۶۰ درخواست در دقیقه در یک دور حداکثر ۳۷ درخواست دارند؛ خانواده جفت‌ها سقف بالاتر دارد. پاسخ‌های هر درخواست به ۲۰MB محدودند. شکست یک فید وضعیت unavailable/partial دارد و مانع استفاده از سایر فیدها نمی‌شود؛ شکست کامل کش سالم قبلی را حفظ می‌کند.

API عمومی مسیر مستندی برای تاریخچه OHLC، همه معاملات یا دارندگان ندارد. نمودار کندلی و ریز معاملات از ویجت رسمی نمایش داده می‌شوند. آمار فارسیِ کش و ویجت زنده ممکن است زمان متفاوت داشته باشند. اطلاعات تبلیغاتی و ادعاهای پروفایل، رتبه‌بندی سرمایه‌گذاری یا تأیید هویت پروژه نیستند.

## TVL ماهانه

DefiLlama در /protocols تغییر یک روز و هفت روز دارد؛ مقدار ماهانه آماده در پاسخ بررسی‌شده نبود. از /protocol/{slug} تاریخچه ۱۰۰ پروتکل بزرگ فعلی (بدون CEX) دریافت می‌شود. تاریخ مبنا نزدیک‌ترین نقطه روزانه در یا قبل از ۳۰ روز گذشته است، با حداکثر فاصله ۴۸ ساعت؛ مبنای مثبت لازم است. رشد = (TVL فعلی / TVL مبنا − ۱) × ۱۰۰؛ افزایش دلاری = فعلی − مبنا. خواندن API، مبنای ذخیره‌شده را با جدیدترین TVL کش ترکیب می‌کند.

تاریخچه هر شش ساعت تازه می‌شود و TVL فعلی هر ساعت. در دریافت اولیه برای ۹۰ پروتکل سابقه کافی موجود بود؛ ۱۰ مورد بدون محاسبه در انتهای رتبه قرار گرفتند. ترتیب پیش‌فرض درصد رشد ماهانه نزولی است؛ افزایش دلاری یا TVL هم قابل انتخاب است. تاریخ مبنا در title سلول و زمان دریافت در صفحه ثبت شده‌اند. این رتبه‌بندی میان همین ۱۰۰ پروتکل است، نه همه ۸۴۹۴ پروتکل منبع و نه همه توکن‌ها. تغییر قیمت دارایی‌ها هم بر رشد دلاری TVL اثر می‌گذارد؛ داده Parent/Child یا دسته‌های مختلف نباید بی‌بررسی جمع زده شوند.

## شواهد این ادامه
- Android SDK از تنظیمات Android Studio پیدا شد: E:/AndroidSdk؛ Android 34 و 35 نصب‌اند، adb اجرا شد و دستگاه متصل ندارد؛ AVD به نام Pixel_7 موجود است.
- Flutter/Dart در PATH و مسیرهای بررسی‌شده پیدا نشدند. دانلود manifest رسمی با HTTP 403 و پیام «service is not available in your location» شکست خورد؛ آینه‌های مستند Flutter نیز 403/404 دادند. تنظیمات سراسری تغییر نکردند.
- pytest نهایی: 40 passed با 3 warning deprecation محیط. پاسخ‌های CMC و OpenAI در آزمون‌ها mock هستند؛ هیچ درخواست پولی واقعی انجام نشد.
- آزمون‌ها شامل بودجه/اعتبار و restart/concurrency، 429/403، metadata، history و entitlement، pagination خبر، dedup/نسخه مقاله، صف و هزینه ترجمه، schema و حفظ اعداد/نمادها، RSS/DNS/redirect/اندازه/XML و rate limit هستند.
- HTTP smoke با Uvicorn واقعی روی localhost:18080 موفق بود؛ فرآیند موقت آزمون متوقف شد. scheduler دمو و compileall نیز اجرا شدند.
- اجرای build-mobile.ps1 پیش از Flutter pub/analyze/test متوقف شد؛ BUILD_STATUS.json دارای checks خالی و apk=null است. این خطا شاهد build موفق نیست.
- وابستگی Python در requirements-lock.txt شامل ۲۲ بسته از closure پروژه است. فایل‌های کاربر حفظ شده‌اند؛ پوشه مخزن Git نیست.

## ادامه دقیق
۱. مسیر flutter.bat نصب‌شده را مشخص کنید یا دسترسی دانلود SDK فراهم شود. سپس scripts/build-mobile.ps1 -Flutter PATH -AndroidSdk E:/AndroidSdk اجرا شود؛ resolver، l10n، analyzer و tests باید واقعاً اجرا و خطاها اصلاح شوند.
۲. روی Pixel_7 جریان‌ها، آفلاین، تم‌ها، متن بزرگ، RTL و TalkBack بررسی و با capture-device.py تصویر واقعی ثبت شود. تست‌های نوشته‌شده به‌تنهایی اثبات اجرای دستگاه نیستند.
۳. APK debug پس از build موفق نصب و مسیر و SHA-256 ثبت شود. روش signing/AAB در DEPLOYMENT است؛ کلید انتشار موجود نیست.
۴. CMC، منابع دارای مجوز و ترجمه live فقط با تنظیم صریح سرور و بودجه فعال شوند؛ آزمون واقعی دسترسی و کیفیت هنوز باز است.

## ادامه پس از درخواست مجدد
- فهرست اخبار به SliverList.builder تبدیل شد تا کارت‌های خارج از viewport همگی ساخته نشوند.
- دریافت صفحه بعد اکنون generation دارد؛ refresh پاسخ دیررس صفحه قبلی را کنار می‌گذارد و درخواست تکراری هم‌زمان نمی‌فرستد. شکست refresh از طریق RetryView نمایش داده می‌شود.
- تست رگرسیون news_pagination_test.dart برای پاسخ دیررس پس از refresh نوشته شد؛ هنوز به علت نبود Flutter اجرا نشده است.
- build report زمان UTC و مسیر SDK را ثبت می‌کند؛ مجموعه integration دمو در حالت live اجرا نمی‌شود.
- بررسی UTF-8 همه فایل‌های Dart و JSON منابع ARB و parser PowerShell و compileall موفق بود. این بررسی‌ها جای analyzer نیستند.
- HTTP smoke دوباره با API واقعی محلی موفق شد. بک‌اند از اجرای ۴۰ تست قبلی تغییر نکرده است.
- جست‌وجوی مسیرهای بیشتر در D:/Program، D:/Software، D:/repos، E:/py، F:/Program و C:/Temp Flutter پیدا نکرد؛ جست‌وجوی گسترده F بدون نتیجه و به دلیل حجم/مسیرهای غیرقابل دسترسی متوقف شد، بنابراین نبودن SDK در تمام دستگاه ادعا نمی‌شود.
- آخرین اجرای build-mobile با AndroidSdk=E:/AndroidSdk همچنان در یافتن flutter متوقف شد؛ APK و screenshot موجود نیستند. برای ادامه وابسته به ابزار، مسیر flutter.bat یا آرشیو SDK از کاربر درخواست شد.

## رفع گزارش خطای وب
- پس از گزارش کاربر، web-config و market از 8080 و health از 8000 HTTP 200 داشتند؛ market دارای ۱۰۰ کوین live بود.
- DataClient با fetch واقعی از proxy موفق بود. اجرای app.js با DOM جایگزین در Node، ۲۰ ردیف و صفحه بازار بدون حالت error تولید کرد؛ این تست، بررسی بصری مرورگر نیست.
- خطا در آزمون کد تکرار نشد؛ کش قدیمی مرورگر علت محتمل است، نه علت قطعی اثبات‌شده. assets به دریافت network-first با fallback آفلاین تغییر یافتند و فایل‌های ورودی نسخه v8 دارند تا کد قدیمی باقی نماند.
- پیام خطای 503/502/timeout/قطع ارتباط اکنون متفاوت است. ۹ تست وب و check و HTTP smoke پس از اصلاح موفق‌اند.
- تأیید روی مرورگر کاربر هنوز انجام نشده؛ محدودیت تأیید خودکار مرورگر از مرحله قبل باقی است. کاربر باید صفحه را سخت‌تازه‌سازی کند و در صورت تداوم، متن جدید خطا را گزارش دهد.
